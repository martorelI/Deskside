# Deckside

Windows desktop tool that manages Active Directory users and computers inside specific organizational
units: creates users (next sequential account name, e-mail from name and surname), pre-stages computers
with their security groups, disables and moves employees who left, assigns group profiles, and reports
expired, inactive or locked-out objects with an Excel export. Every change is previewed, confirmed and
recorded. English and Spanish.

Status: phase 1 (Core logic and tests) in progress; see `docs/ROADMAP.md`.
